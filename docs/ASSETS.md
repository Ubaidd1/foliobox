This reconstruction is not the original artist's standalone portrait file.

These three Unsplash image endpoints were opened successfully with the web lookup tool. They remain externally served with responsive crop parameters; direct local downloading was unavailable. Their final remote rendering was not browser-tested. Project cards have reserved geometry and a bundled fallback asset if an external image fails. Download properly licensed original photography for a fully offline production package.
